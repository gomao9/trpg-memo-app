# TRPG Memo - Windows 向けコンパクト付箋ツール

TRPGセッション中、ココフォリアやキャラクターシート等からドラッグした固有名詞を、画面端に最前面で常時表示しておくための小型メモアプリです。

## 機能

### 基本機能
- **常に最前面表示**: ゲーム画面やシート作成中も、メモが常に見える状態で画面上部に表示
- **タイトルバーなし**: コンパクトな付箋風UIで画面を圧迫しない
- **テキスト入力・編集**: 各行のテキスト欄は後から直接編集可能
- **削除機能**: 各行の「×」ボタンで不要な行を即座に削除
- **行追加ボタン**: 下部の「+」ボタンで空行を手動で追加可能
- **スクロール対応**: 行数が増えてもリスト部分は縦スクロール可能
- **メモの自動保存**: 追加・編集・削除した内容をローカルに保存し、次回起動時に復元
- **単語セットの切り替え**: セット選択欄から登録済みの単語セットを切り替え、「+セット」から新しいセットを追加
- **メモの詳細表示**: 行を右クリックすると、登録した詳細を表示
- **詳細の編集**: 各行の鉛筆ボタン、または詳細表示の「詳細を編集」から編集
- **メモの並べ替え**: 各行左側の「≡」をドラッグして上下に移動
- **グローバルショートカット**: 選択中のテキストを Alt+Z でコピーしてメモに追加

### テキスト処理
- ドロップされたテキストの前後の空白や改行コードを自動でトリム（除去）
- 固有名詞がすぐに入力可能な「固有名詞」プレースホルダ表示

### UI設計
- 画面端に収まるコンパクトサイズ（300×420px）
- 付箋風の暖色カラースキーム（黄系背景）
- 1行ごとに「テキスト入力欄 + 削除ボタン」のシンプルレイアウト

## 必要な環境

- **OS**: Windows 7 以上
- **Go**: 1.22 以上

## ビルド方法

### 1. リポジトリをクローン
```bash
git clone https://github.com/gomao9/trpg-memo-app.git
cd trpg-memo-app
```

### 2. Go モジュール初期化
```bash
go mod init trpgmemo
```

### 3. 依存パッケージを取得
```bash
go get fyne.io/fyne/v2@latest
go get golang.org/x/sys/windows@latest
```

### 4. Windows 向けビルド
```bash
go build -o trpgmemo.exe .
```

**コンソール画面を出さないようにしたい場合:**
```bash
go build -ldflags="-H windowsgui" -o trpgmemo.exe .
```

### 5. 実行
生成された `trpgmemo.exe` をダブルクリックして起動します。

```bash
.\trpgmemo.exe
```

## 使い方

1. **アプリを起動** → 画面の右側に小さな付箋が表示されます
2. **固有名詞を入力** → 各行の入力欄に直接タイプするか、他のアプリからドラッグして落とします
3. **編集・削除** → 入力欄を編集するか、「×」ボタンで削除します
4. **新しい行を追加** → 下部の「+」ボタンを押して空行を追加します
5. **終了** → ヘッダー右上の「×」ボタンでアプリを終了します
6. **移動・サイズ変更** → 上部のヘッダーをドラッグして移動し、ウィンドウの端をドラッグしてサイズを調整できます
7. **選択テキストを追加** → 他のアプリでテキストを選択して Alt+Z を押すと、そのテキストがメモに追加されます
8. **並べ替え** → 行の左側にある「≡」を上下にドラッグします。ドラッグ中は行がはっきりしたオレンジ色の半透明表示と枠で強調され、ハンドルもオレンジ色に変わります。並び順は自動保存されます
9. **詳細の表示・編集** → 行を右クリックすると詳細を全て表示します。各行の鉛筆ボタン、または表示内の「詳細を編集」から編集できます。本文は入力欄をクリックして直接編集できます

単語セットは画面上部の選択欄から切り替えられます。「+セット」を押して名前を入力すると新しいセットが追加され、切り替え後も各セットの内容は個別に保存されます。メモとすべての単語セットは、ユーザー設定フォルダー内の `trpg-memo-app/memos.json` 1ファイルに保存されます。従来のメモデータは「単語セット 1」として引き継がれます。
